## Wise 介绍

Wise（前身为TransferWise）成立于2011年，是一家总部位于英国伦敦的金融科技公司，专注于提供国际汇款和多币种账户服务。作为全球领先的跨境支付平台之一，Wise目前服务超过1600万用户，每月处理超过100亿美元的跨境转账。

Wise的核心优势在于采用真实汇率（即路透社等金融机构使用的中间市场汇率）进行货币兑换，而非传统银行那种加价后的汇率。这意味着用户能看到透明的费用明细——一笔固定的小额手续费，而不是隐藏在汇率差价中的高额成本。相比传统银行，Wise的国际转账费用通常能节省高达8倍。

平台支持160多个国家的50多种货币转账，覆盖了全球主要的汇款路线。除了基础的汇款服务，Wise还提供多币种账户（支持持有和管理40多种货币）、Wise借记卡（可在全球ATM取现和刷卡消费）、批量支付（适合企业用户）等功能。对于经常进行跨境交易的个人、自由职业者、跨境电商卖家和中小企业来说，Wise已经成为不可或缺的金融工具。

在安全性方面，Wise受到英国金融行为监管局（FCA）监管，并在多个国家和地区持有相应的金融服务牌照。用户资金与公司运营资金分离保管，确保即使公司出现问题，客户资金也能得到保护。
